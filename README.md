# Trelis Life
**Structure for a better life.**

Trelis Life is an offline-first, modular Health Operating System built with Next.js 15. It focuses on psychological resilience and biological stability through a "System 1" frictionless interaction model.

## Core Features
- **Offline-First:** Full functionality without internet using Zustand persistence.
- **Widget OS:** Modular dashboard where you can toggle biological/psychological trackers.
- **Ritual Loops:** Guided Morning and Evening rituals based on Fogg behavioral principles.
- **Biometric Tracking:** Sleep, Mood, Digestion, Food Diversity, and Movement.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS v4 + Framer Motion
- **State:** Zustand
- **Database:** Supabase (Auth & Sync coming in Phase 2)
- **Native:** Capacitor 6 (Haptic Feedback)

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)
